How SVM Works

  1. Maximal Margin Search: Rather than any separating line, SVM finds the decision boundary that maximises the geometric distance (the margin) to the nearest training point of either class.
  2. Support Vectors Define Everything: Only the critical points on or inside the margin bounds — the support vectors — determine the final hyperplane. Every other training point is irrelevant; removing non-support-vector points does not change the solution.
  3. Soft Margin via C: Real data is rarely linearly separable. Slack variables (ξi ≥ 0) permit controlled margin violations. Parameter C weighs maximising margin width against penalising each violation.
  4. The Kernel Trick (RBF): For non-linearly separable data, the RBF kernel implicitly maps inputs into an infinite-dimensional feature space where they become linearly separable — computed efficiently via K(x, x') = exp(−γ ||x − x'||²) without ever materialising those coordinates.
Try it: Switch to Kernel: RBF — the boundary wraps into closed contours around clusters. Increase γ to tighten those contours until the model overfits; decrease C to widen the margin until it ignores outliers. Then return to Linear to compare the stark difference.

Detailed Algorithm Explanation

1. Mathematical Optimization & Dual Formulation

The SVM training problem is a strictly convex quadratic program, guaranteeing a unique global optimum:

  • Primal (Soft-Margin):
    min ½||w||2 + C · ∑ ξi
    subject to yi(w · xi + b) ≥ 1 − ξi,   ξi ≥ 0
  • Decision Function: The hyperplane is f(x) = w · x + b = 0; margin planes sit at f(x) = ±1. Geometric margin width = 2 / ||w||.
  • Dual & Support Vectors: Via Lagrange multipliers αi, the solution is:
    f(x) = ∑ αi yi K(xi, x) + b
    Points where αi > 0 are the support vectors.
  • RBF Kernel: K(x, x') = exp(−γ ||x − x'||2). Valid inner product in a reproducing kernel Hilbert space (Mercer's theorem).

2. Hyperparameter Dynamics: C and Gamma (γ)

Correct joint tuning of C and γ is the most critical step in deploying a kernel SVM:

  • C — Regularisation:
    • Large C: Heavy penalty on misclassification → narrow margin, strict boundaries → overfitting risk.
    • Small C: Tolerates margin violations → wide, smooth boundary → possible underfitting.
  • γ — RBF radius of influence:
    • High γ: Influence is hyper-local; boundary forms tight islands around individual support vectors (high variance).
    • Low γ: Influence is broad; smooth sweeping boundary capturing global structure (high bias).
  • Best practice: Always tune C and γ jointly via a logarithmic grid search with cross-validation.

Best Use Cases for SVM

Bioinformatics

Genomic & Cancer Tissue Classification

SVMs excel when features vastly outnumber samples (e.g., microarrays with 20,000 gene expression features across 100 patients). The maximum-margin principle resists overfitting even in extreme high-dimensional settings.

NLP & Text

High-Dimensional Text Categorisation

Linear SVM is a standard strong baseline for spam filtering, sentiment analysis, and topic categorisation. Sparse TF-IDF vectors in tens-of-thousands of dimensions are typically linearly separable, making LIBLINEAR the ideal engine.

Vision

Object Detection & Pedestrian Tracking

Classic computer vision pipelines pair HOG (Histogram of Oriented Gradients) feature descriptors with a Linear or RBF SVM for rapid, reliable object bounding-box verification — still used as a strong baseline for embedded systems.

Security

One-Class SVM for Novelty Detection

By drawing a tight boundary enclosing normal system behaviour in kernel space, One-Class SVM flags zero-day network intrusions or unusual industrial machinery telemetry without requiring anomaly training labels.

Implementation Details & How Scikit-Learn Does It

Scikit-learn's SVM is a wrapper around two distinct, battle-tested C++ libraries: LIBSVM (for SVC, NuSVC) and LIBLINEAR (for LinearSVC). Choosing correctly between them is the single biggest lever for scalable performance.

LIBSVM vs LIBLINEAR

  • SVC — LIBSVM: Solves the dual QP problem via the Sequential Minimal Optimisation (SMO) algorithm. Time complexity: O(N2 × D) to O(N3 × D) (N = samples, D = features). Practical ceiling is ~50,000 samples before training latency becomes prohibitive. Supports RBF, polynomial, and sigmoid kernels. Multiclass strategy: One-vs-One — trains N(N−1)/2 binary classifiers internally.
  • LinearSVC — LIBLINEAR: Uses coordinate descent or trust-region Newton methods on the primal — no kernel matrix required. Time complexity: O(N × D). Scales to millions of sparse samples. Multiclass strategy: One-vs-Rest — trains N binary classifiers. Minimises squared hinge loss by default (unlike SVC which uses standard hinge loss).
  • Primal vs Dual: LIBLINEAR can optionally solve the primal when N > D, saving significant training time over the dual formulation.

Scikit-Learn Example Code

from sklearn.svm import SVC, LinearSVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

# SVM is distance-based: always standardise first
rbf_model = make_pipeline(
    StandardScaler(),
    SVC(
        C=1.0,
        kernel='rbf',    # One-vs-One multiclass (LIBSVM)
        gamma='scale',   # 1/(n_features * X.var())
        probability=False # True adds costly Platt scaling
    )
)

# For large / sparse datasets use LinearSVC instead
linear_model = make_pipeline(
    StandardScaler(),
    LinearSVC(
        C=1.0,           # One-vs-Rest multiclass (LIBLINEAR)
        max_iter=2000
    )
)

rbf_model.fit(X_train, y_train)
sv = rbf_model.named_steps['svc'].support_vectors_

Crucial Considerations When Using SVM

1. Mandatory Feature Scaling

SVM optimises margins using Euclidean distance. A feature on the scale of 0–500,000 (e.g., annual income) will completely dominate the kernel dot-product over a 0–1 feature (e.g., click rate), distorting margin geometry entirely. Always apply StandardScaler or MinMaxScaler before fitting any SVM variant.

2. Quadratic-to-Cubic Scaling with Samples

Kernel SVMs (LIBSVM) scale between O(N2 × D) and O(N3 × D). A dataset of 100,000 rows can make training take hours. For large data, use SGDClassifier(loss='hinge') or LinearSVC, or apply Nyström kernel approximation to retain non-linearity at lower cost.

3. No Native Probability Outputs

SVM outputs a signed distance f(x), not a probability. Setting probability=True triggers 5-fold internal cross-validation to fit a Platt-scaling logistic regression on top — increasing training time substantially and sometimes degrading ranking quality.

4. RBF Overfitting via High Gamma

An excessively high γ causes the model to form disconnected micro-islands around each support vector, achieving 100% training accuracy while completely failing on unseen data. Always tune C and γ jointly via log-scale grid search cross-validation — never tune them independently.

5. Non-Linear Kernel Interpretability

Linear SVM exposes feature weights directly via coef_[0], enabling straightforward feature-importance analysis. RBF and polynomial kernels project data into implicit infinite-dimensional spaces — individual feature contributions become uninterpretable without external tools like SHAP or permutation importance.
