Simple Linear Regression Interactive Guide

Simple Linear Regression models the relationship between one input feature (x) and one continuous output (y) as a straight line: ŷ = w·x + b. The slope w and intercept b are found by minimising the Mean Squared Error using Gradient Descent — an iterative optimisation algorithm that nudges the line step-by-step toward the best fit. This is the foundational building block of all of deep learning.

How Simple Linear Regression Works

  1. The Model — A Straight Line: We predict y using ŷ = w·x + b. The slope w tells us: "for every 1 unit increase in x, y changes by w units." The intercept b is the predicted y when x = 0. We start with w = 0, b = 0 (the flat line at zero) and use gradient descent to improve these parameters.
  2. The Loss — Mean Squared Error: To measure how wrong our current line is, we compute the vertical gap between each data point and the line (the residual = ŷ−y), square it (penalises large errors more), and average all N of them. MSE = (1/N)Σ(ŷi−yi)². Lower is better; 0 = perfect fit.
  3. The Gradient — Which Direction to Move? The gradient of MSE tells us the direction of steepest increase for each parameter:
    • ∂MSE/∂w = (2/N)Σ(ŷi−yi)·xi
    • ∂MSE/∂b = (2/N)Σ(ŷi−yi)
    Moving in the opposite direction decreases MSE.
  4. Gradient Descent — Iterative Refinement: Update w ← w − η·∂MSE/∂w and b ← b − η·∂MSE/∂b. Repeat. Each step moves the line closer to the best fit. The learning rate η controls how large each step is — too large and the line overshoots, too small and convergence is very slow.

Detailed Algorithm Explanation

1. Why MSE? The Loss Function Explained

We need a single number that measures how wrong our current line is across all data points. MSE is the standard choice — here's why each design decision matters:

  • MSE formula:
    MSE = (1/N) Σ(ŷi − yi)2
  • Why squared (not absolute)? Squaring makes large errors disproportionately expensive — a residual of 10 contributes 100 to MSE, forcing the model to prioritise reducing its worst mistakes. It also makes the loss function smooth and differentiable everywhere, which is essential for gradient descent.
  • Why (1/N)? Averaging over N points makes MSE independent of dataset size — doubling the data doesn't double the loss.
  • RMSE = √MSE is often reported because it is in the same units as y, making it directly interpretable as the typical prediction error.
  • Why GD is guaranteed to work here: MSE is a strictly convex function of w and b (a quadratic bowl with one unique minimum). There are no local minima — gradient descent always finds the global optimum.

2. Gradient Descent — The Maths Behind Each Step

Gradient descent uses calculus to find which direction to nudge each parameter to decrease MSE. Here is the full derivation for one step:

  • Step 1 — Compute residuals: For the current w and b, compute erri = ŷi − yi = (w·xi + b) − yi for each training point.
  • Step 2 — Compute gradients (chain rule):
    ∂MSE/∂w = (2/N) Σ erri · xi
    ∂MSE/∂b = (2/N) Σ erri
  • Step 3 — Update parameters (step opposite the gradient):
    w ← w − η · ∂MSE/∂w
    b ← b − η · ∂MSE/∂b
  • Learning rate η: Controls step size. If η is too large, the update overshoots the minimum and MSE oscillates. If too small, convergence is very slow. The "Goldilocks" value is typically found by tuning.
  • Convergence: Stop when the gradient magnitude falls below a threshold (∇J ≈ 0) or after a fixed number of iterations. At the minimum, ∂MSE/∂w = 0 and ∂MSE/∂b = 0 exactly.

Best Use Cases for Linear Regression

Real Estate

House Price Prediction

Predicting sale price from a single strong predictor — floor area, number of rooms, or distance to city centre. Linear regression is the first baseline every housing analyst runs before trying complex tree-based or neural-network models. Its coefficients are directly interpretable: "each additional square metre adds £2,300 to the price."

Marketing

Sales & Advertising Forecasting

Modelling how TV spend, online ad budget, or store footfall linearly drives revenue. The slope directly quantifies the return on investment: "each £1,000 increase in ad spend yields £4,200 in incremental revenue." This interpretability makes linear regression the standard tool for marketing mix modelling.

Medicine

Drug Dosage Calibration

Relating patient body weight or surface area to the correct drug dosage. The linear relationship is often pharmacologically motivated — clearance rates scale linearly with body mass. Here, interpretability and simplicity are critical for regulatory approval and clinical adoption.

Climate Science

Trend Analysis & Forecasting

Fitting a linear trend to time-series data: CO&sub2; concentration rising over decades, global temperature anomalies, or sea-level rise. The slope becomes the rate of change — a scientifically meaningful quantity. Linear regression on log-transformed data models exponential growth.

Implementation in Scikit-Learn

There are two distinct ways to fit a linear regression in sklearn: Ordinary Least Squares (exact closed-form solution — no gradient descent) and Stochastic Gradient Descent (iterative, required for very large datasets). They solve the same problem but with different algorithms and different sensitivity to feature scaling.

OLS vs SGD — When to Use Which

  • LinearRegression (OLS): Uses Singular Value Decomposition to find the mathematically exact optimal w and b in a single computation. Not iterative — no learning rate, no convergence concerns. Scale-invariant: no StandardScaler needed. Best for small-to-medium datasets (<100k rows).
  • SGDRegressor (Gradient Descent): Updates parameters iteratively on mini-batches (stochastic). Requires StandardScaler — unscaled features make gradient magnitudes wildly unequal, causing divergence. Best for very large datasets or online learning where data arrives incrementally.
  • Key parameters for SGDRegressor:
    • eta0: initial learning rate (default 0.01)
    • learning_rate: schedule — 'constant', 'invscaling' (decreases over time), 'adaptive'
    • max_iter: maximum passes over the data
    • tol: convergence tolerance (stop when improvement < tol)
    • penalty: 'l2' (Ridge), 'l1' (Lasso), 'elasticnet'

Scikit-Learn Code

import numpy as np
from sklearn.linear_model  import LinearRegression, SGDRegressor
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline      import make_pipeline
from sklearn.metrics       import mean_squared_error, r2_score

# ── Method 1: Ordinary Least Squares ────────────────────
# Exact SVD solution — no iterations, no scaling required

# 1. Create
ols = LinearRegression()
# 2. Fit
ols.fit(X_train, y_train)
# 3. Predict
y_pred_ols = ols.predict(X_test)
# 4. Extract coefficients
print(f"Slope:     {ols.coef_[0]:.4f}")
print(f"Intercept: {ols.intercept_:.4f}")
# 5. Evaluate
print(f"R²:        {r2_score(y_test, y_pred_ols):.4f}")
print(f"RMSE:      {np.sqrt(mean_squared_error(y_test, y_pred_ols)):.4f}")

# ── Method 2: SGD Regressor ─────────────────────────────
# Gradient descent — StandardScaler is mandatory; omitting it causes divergence

# 1. Create (StandardScaler must be inside the pipeline)
sgd = make_pipeline(
    StandardScaler(),
    SGDRegressor(
        eta0=0.01,                  # Initial learning rate
        learning_rate='invscaling',  # LR decreases each step
        max_iter=1000,
        tol=1e-4,                   # Stop when improvement < tol
        penalty='l2',               # Ridge regularisation
        random_state=42
    )
)
# 2. Fit
sgd.fit(X_train, y_train)
# 3. Predict
y_pred_sgd = sgd.predict(X_test)
# 4. Extract coefficients (stored in normalised feature space)
sgd_reg = sgd.named_steps['sgdregressor']
print(f"Slope (normalised): {sgd_reg.coef_[0]:.4f}")
print(f"Intercept:          {sgd_reg.intercept_[0]:.4f}")
# 5. Evaluate
print(f"R²:                 {r2_score(y_test, y_pred_sgd):.4f}")
print(f"RMSE:               {np.sqrt(mean_squared_error(y_test, y_pred_sgd)):.4f}")

Crucial Considerations for Linear Regression

1. SGD Diverges Without Feature Scaling — OLS Does Not

If you use gradient descent (SGDRegressor) with unscaled features, gradient magnitudes will be wildly different in each dimension — a feature measured in thousands will produce gradients thousands of times larger than a feature measured in single digits. The update step sizes become unbalanced, causing the algorithm to bounce chaotically rather than converge. Always use StandardScaler inside a pipeline with any gradient-based linear model. LinearRegression (OLS) is immune to this — it computes the exact algebraic solution regardless of feature scale.

2. Linearity Assumption May Not Hold

Linear regression assumes y and x have a linear relationship. In reality, many real-world relationships are non-linear (e.g., diminishing returns in advertising, exponential disease spread). Always plot your data first (residuals vs. fitted values). If you see a clear curved pattern in the residuals, the linear model is fundamentally misspecified — consider polynomial features (PolynomialFeatures), log transformations, or a non-linear model.

3. Squared Loss Amplifies Outlier Influence

Because MSE squares the residuals, a single outlier with a residual of 50 contributes 2,500 to the loss — potentially more than dozens of normal points combined. The fitted line gets pulled disproportionately toward outliers. For outlier-robust regression, use Huber loss (HuberRegressor in sklearn), which behaves like squared loss for small residuals but linearly for large ones.

4. Model May Underfit Non-Linear Data

Simple linear regression has only two parameters (w, b) — a very low capacity model. If the true relationship involves interactions, curvature, or thresholds, the linear model will systematically underfit. Check the R² score: values below 0.7 often signal that a more flexible model (polynomial regression, decision tree, or neural network) would better capture the underlying pattern.

5. Extrapolation Is Unreliable

A linear model confidently predicts values far outside the training range — but these extrapolated predictions may be physically impossible or wildly wrong. A model trained on house sizes 50–200 m² will predict a 0 m² house has a positive (nonsensical) value, or a 1,000 m² house has an astronomically high price. Always flag when a prediction falls outside the training range and treat it with caution.
